# 🎨 Imagine AI — Free Image Generator

Pollinations.ai se powered, 100% free AI image generator.

## Features
- ✅ Bilkul free — koi API key nahi
- ✅ 10 different styles
- ✅ 4 image sizes
- ✅ 3 AI models (Fast, Realistic, Turbo)
- ✅ Gallery — recent images save hoti hain
- ✅ Download button
- ✅ Random prompts
- ✅ Mobile friendly

## 🚀 GitHub Pages Par Deploy Kaise Karein (FREE)

### Step 1: GitHub Account Banayein
- https://github.com par jayein
- Sign up karein (free)

### Step 2: New Repository Banayein
1. GitHub par "+" button → "New repository"
2. Name: `imagine-ai` (ya koi bhi naam)
3. Public select karein
4. "Create repository" click karein

### Step 3: Files Upload Karein
1. Repository page par "uploading an existing file" click karein
2. Yeh teen files upload karein:
   - `index.html`
   - `style.css`
   - `script.js`
3. "Commit changes" click karein

### Step 4: GitHub Pages Enable Karein
1. Repository → Settings → Pages
2. Source: "Deploy from a branch"
3. Branch: `main` → `/root`
4. Save click karein

### Step 5: Live! 🎉
2-3 minute mein aapki site live hogi:
```
https://YOUR-USERNAME.github.io/imagine-ai/
```

## 💡 Tips
- Ctrl+Enter se bhi generate kar sakte hain
- Seed number same rakho — same image dobara aayegi
- HD size thoda slow hoga (1024×1024)
- Images download karke save karein — gallery session ke baad reset hoti hai
